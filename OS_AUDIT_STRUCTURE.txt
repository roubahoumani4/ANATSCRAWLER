┌─ DATA FLOW ────────────────────────────────────────────────────────────────┐
│                                                                              │
│  1. USER REGISTERS MACHINE                                                  │
│     Frontend → POST /machines/register → Backend                            │
│     → Generate machineId & agentInstallationToken                           │
│     → MongoDB: Save to os_audit_machines                                     │
│     ← Return agentInstallationToken                                          │
│                                                                              │
│  2. AGENT INSTALLED & RUNS AUDIT                                            │
│     User Machine → /opt/anat-os-audit/agent.sh                              │
│     → Run Lynis audit                                                       │
│     → Parse results (score, warnings, suggestions)                          │
│     → POST /reports with agentInstallationToken                             │
│                                                                              │
│  3. REPORT SUBMITTED                                                        │
│     Backend → Validate token                                                │
│     → Update machine agentStatus to "active"                                │
│     → Create OSAuditReport                                                   │
│     → MongoDB: Save report + update machine lastAuditDate                   │
│     ← Return success                                                        │
│                                                                              │
│  4. USER VIEWS DASHBOARD                                                    │
│     Frontend → GET /stats → Show statistics                                 │
│     Frontend → GET /machines → Show all machines                             │
│     Frontend → GET /reports → Show all reports                              │
│     ← MongoDB: Query and return data                                         │
│                                                                              │
└────────────────────────────────────────────────────────────────────────────┘
